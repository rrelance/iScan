# iScan

Scan a home gym with an iPhone's LiDAR and camera, model it with Claude, and rearrange the equipment in a browser planner. The iOS capture app is built on GitHub Actions and installed with TrollStore; scans upload over Wi-Fi to a small server on the PC.

## Install on phone

Open this link in Safari on the iPhone, then Share → TrollStore → Install:

https://github.com/rrelance/iScan/releases/download/nightly/iScan.ipa

The `nightly` release is rebuilt on every push to `main`.
